🪜 Passo a Passo para Replicar
PASSO 1
📅 Defina os 3 jogos do CAD
Confirme as datas, kickoffs e janelas de parada para os 3 jogos da fase. Identifique o dia da semana de cada jogo para mapear a coluna correta nos dados históricos.

Exemplo BRPE01:
J1 = Sáb 13/06 → coluna "sáb"
J2 = Sex 19/06 → coluna "sex"
J3 = Qua 24/06 → coluna "qua"
PASSO 2
📊 Extraia os dados históricos
No BigQuery, rode a query de THP histórico por CPT e dia da semana (últimas 4 semanas (média)). Exporte o resultado com as colunas:

CPT | dom | seg | ter | qua | qui | sex | sáb

Uma tabela para VOLUME e uma para POSIÇÕES STAGE OUT.
PASSO 3
⬆ Defina as antecipações de CPT
Identifique quais CPTs serão antecipados e para qual hora. Padrão utilizado:

• CPT 19h → antecipado 2h antes da janela
• CPT 20h → antecipado 1h antes da janela

Preencher VOLUME ANTECIPADO e POSIÇÕES ✓ com os dados do CPT 19/20 do dia do jogo.
PASSO 4
🎯 Defina as estratégias de turno
Para cada jogo, alinhe com Ops:

• T2: HE entrada antecipada? HE extensão? Horário de refeição?
• T3: entrada normal ou antecipada em HE?
• T4: opera normalmente, folga, ou saída antecipada?

Cada decisão vira um card de estratégia na aba do jogo.
PASSO 5
🤖 Cole o prompt na IA
Abra o Claude (claude.ai) ou ChatGPT. Cole o prompt acima preenchendo os campos entre colchetes [ ] com as informações do seu CAD.

Solicite o arquivo como HTML único para upload no Grid Admin.
